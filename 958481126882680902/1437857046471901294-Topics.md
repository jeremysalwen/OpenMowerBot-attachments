#Publish:
| Topic                            | Type                         |                        How often | Where it’s published  | Notes                                                                                        |
| -------------------------------- | ---------------------------- | -------------------------------: | --------------------- | -------------------------------------------------------------------------------------------- |
| `ll/mower_status`                | `mower_msgs/Status`          |          ~50 Hz (timer @ 0.02 s) | `publishStatus()`     | Overall LL/HL status bits, mower ESC telemetry copied into fields.                           |
| `ll/power`                       | `mower_msgs/Power`           |                           ~50 Hz | `publishStatus()`     | Battery/charge voltages & current; `charger_enabled`/`charger_status`.                       |
| `ll/emergency`                   | `mower_msgs/Emergency`       |                           ~50 Hz | `publishStatus()`     | `active_emergency` from LL bitmask; `latched_emergency` if either HL or LL emergency is set. |
| `ll/diff_drive/measured_twist`   | `geometry_msgs/TwistStamped` | ~50 Hz (after first tick sample) | `publishStatus()`     | Derived from left/right tacho deltas; `header.frame_id = "base_link"`.                       |
| `ll/diff_drive/left_esc_status`  | `mower_msgs/ESCStatus`       |                           ~50 Hz | `publishStatus()`     | From `xesc_driver` left status.                                                              |
| `ll/diff_drive/right_esc_status` | `mower_msgs/ESCStatus`       |                           ~50 Hz | `publishStatus()`     | From `xesc_driver` right status.                                                             |
| `ll/imu/data_raw`                | `sensor_msgs/Imu`            |        On IMU packets (variable) | `handleLowLevelIMU()` | Populates linear accel & angular vel; `frame_id = "base_link"`.                              |


# Subscribe:
| Topic                        | Type                         |                           Queue | Callback                    | What it does                                                                                        |
| ---------------------------- | ---------------------------- | ------------------------------: | --------------------------- | --------------------------------------------------------------------------------------------------- |
| `ll/cmd_vel`                 | `geometry_msgs/Twist`        | `0` (unbounded queue in roscpp) | `velReceived()`             | Converts v/ω to left/right duty cycles (clamped to ±1). Updates command timeout. Uses `tcpNoDelay`. |
| `/mower_logic/current_state` | `mower_msgs/HighLevelStatus` |                             `0` | `highLevelStatusReceived()` | Forwards HL state & GPS quality to the LL board over serial.                                        |
